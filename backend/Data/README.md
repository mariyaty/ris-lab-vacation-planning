# Data — слой доступа к данным

Папка предназначена для контекста базы данных и компонентов доступа к данным.

В ЛР7 здесь находится `ApplicationDataContext.cs` — каркас будущего контекста.
Он пока не подключён к Entity Framework Core и PostgreSQL и не выполняет
чтение или запись заявок. Реализация хранения данных будет добавлена
в следующих лабораторных работах.

Важно: наличие этой заготовки не означает, что заявки уже сохраняются
на сервере или в базе данных.
