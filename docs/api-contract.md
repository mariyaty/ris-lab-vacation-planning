# Контракт API

## 1. Общие сведения

Клиентское приложение Vue 3 взаимодействует с сервером ASP.NET Core по HTTP. Данные передаются в формате JSON. Базовый адрес API: `http://localhost:5000`.

Основной ресурс ЛР8 — `/api/vacation-requests` (заявки на планирование отпусков).

## 2. Маршруты

| Метод и путь | Назначение | Успешный ответ |
|---|---|---|
| `POST /api/vacation-requests` | Создать заявку | `201 Created` |
| `GET /api/vacation-requests` | Получить список, включая пустой | `200 OK` |
| `GET /api/vacation-requests/{id}` | Получить одну заявку | `200 OK` |
| `PATCH /api/vacation-requests/{id}/assignee` | Назначить ответственного | `200 OK` |
| `PATCH /api/vacation-requests/{id}/status` | Изменить статус | `200 OK` |

`DELETE` в ЛР8 не реализуется. Назначение ответственного и изменение статуса — отдельные PATCH.

## 3. Создание заявки

Клиент передаёт только изменяемые поля:

```json
{
  "title": "Планирование отпусков участка связи",
  "siteId": 2,
  "description": "Подготовить проект графика отпусков работников участка связи."
}
```

Проверки: `title` — 5–80 символов; `description` — 10–500 символов; `siteId` — целое число больше нуля.

Сервер формирует `id`, `number`, `status = "New"`, `createdByUserId`, пустой `assigneeUserId` и `createdAt`.

## 4. Формат ответа

```json
{
  "id": 1,
  "number": "VR-00001",
  "title": "Планирование отпусков участка связи",
  "siteId": 2,
  "description": "Подготовить проект графика отпусков работников участка связи.",
  "status": "New",
  "createdByUserId": 5,
  "assigneeUserId": null,
  "createdAt": "2026-11-25T12:00:00Z"
}
```

Дата в примере условная. Фактическое значение формируется сервером.

## 5. Назначение ответственного

```http
PATCH /api/vacation-requests/1/assignee
Content-Type: application/json
```

```json
{ "assigneeUserId": 5 }
```

`assigneeUserId` должен быть положительным целым числом. При успехе возвращается `200 OK` и обновлённая заявка.

## 6. Изменение статуса

```http
PATCH /api/vacation-requests/1/status
Content-Type: application/json
```

```json
{ "status": "InProgress" }
```

Допустимые статусы: `New`, `InProgress`, `Closed`, `Cancelled`. Перевод в `InProgress` без назначенного ответственного запрещён и возвращает `409 Conflict`.

## 7. Коды ошибок

| Код | Причина |
|---|---|
| `400` | Некорректный JSON, поля не прошли валидацию или передан неизвестный статус |
| `404` | Заявка с указанным `id` не найдена |
| `409` | Переход в `InProgress` без назначенного ответственного |
| `500` | Непредвиденная ошибка; клиент получает безопасный `ProblemDetails` |

## 8. Ограничения ЛР8

Заявки хранятся в памяти процесса. После перезапуска backend данные сбрасываются. PostgreSQL не подключается. Проверка фактического существования участка и пользователя, а также проверка роли `Planner` пока не выполняются, поскольку справочники и авторизация ещё не реализованы.
