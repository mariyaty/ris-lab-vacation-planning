# 1. Название и организация

Название системы: ИИ-система планирования графика отпусков и расчёта явочной численности
Организация / подразделение: ОАО «РЖД», подразделение транспортного предприятия
№ из таблицы примеров (если брали): своя тема

# 2. Главная сущность и справочник

Главный объект (одна запись процесса): заявка на планирование отпуска
Справочник (вторая таблица, ссылка числом): участки предприятия
Поле-ссылка (как назовёте в JSON/БД): siteId

# 3. Роли и права

| Роль                          | Создаёт | Назначает | Меняет статус |
| ----------------------------- | ------- | --------- | ------------- |
| Кадровый специалист           | да      | да        | нет           |
| Ответственный за планирование | нет     | нет       | да            |

Исполнитель не назначает себя. Назначение ответственного выполняется отдельным действием кадровым специалистом.

# 4. Сценарий в одно предложение

Кадровый специалист создаёт заявку на планирование отпуска для выбранного участка предприятия, отдельно назначает ответственного за планирование, после чего ответственный обрабатывает заявку и меняет её статус.

# 6. Что не входит в семестр

1. Подключение к реальным информационным системам ОАО «РЖД».
2. Работа с реальными персональными данными сотрудников.
3. Автоматическое принятие кадровых решений без участия сотрудника.
4. Полноценная промышленная ИИ-модель для прогнозирования численности.
5. Интеграция с системами расчёта заработной платы и бухгалтерского учёта.
6. Мобильное приложение.

# 7. Запас под ВКР

Не меньше четырёх направлений развития, которые не реализуются в рамках текущего семестра:

1. Данные/процесс — добавление данных о сотрудниках, должностях, сменах, нормативной численности, остатках и истории отпусков.
2. ИИ — прогнозирование дефицита работников и автоматическое формирование нескольких вариантов графика отпусков.
3. Связи с другими системами — интеграция с кадровыми системами, системами учёта рабочего времени и графиками смен.
4. Масштаб — расширение системы для нескольких подразделений, участков и филиалов транспортного предприятия.
5. Аналитика — формирование расширенных отчётов и показателей кадровой обеспеченности.

# 8. Чем не копия соседа

Проект посвящён другой предметной области и другому процессу: планированию отпусков и расчёту явочной численности работников транспортного предприятия. Главный объект системы — заявка на планирование отпуска. Дополнительно используется ИИ для анализа кадровой обеспеченности и формирования рекомендаций. Роли и сценарий работы также отличаются: кадровый специалист создаёт и назначает заявку, а ответственный за планирование обрабатывает её и изменяет статус.
