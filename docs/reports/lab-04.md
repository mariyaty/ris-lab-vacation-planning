# Отчёт по лабораторной работе № 4

**Дисциплина:** Технология разработки информационных систем  
**Тема:** Vue 3: компоненты и маршруты  
**Выполнила:** Крец Мария Романовна  
**Группа:** ТРИС-1-23  
**Проект:** ИИ-система планирования графика отпусков и расчёта явочной численности для транспортного предприятия (заказ РЖД)

## Цель работы

Разделить существующее клиентское приложение на компоненты и страницы, настроить маршрутизацию с помощью Vue Router и обеспечить передачу списка заявок в компонент таблицы через props.

## Используемые средства

- Vue 3;
- JavaScript;
- Vite;
- Vue Router;
- Git и GitHub Codespaces.

## Ход работы

1. В проект добавлена зависимость `vue-router`.
2. Создан файл `router.js` с маршрутами `/`, `/new` и `/login`.
3. В `main.js` подключён маршрутизатор через `app.use(router)`.
4. Компонент `App.vue` организован как общий макет приложения: `AppHeader` и верхняя панель остаются постоянными, а содержимое страниц отображается в `RouterView`.
5. Боковая навигация вынесена в `components/AppHeader.vue`.
6. Таблица заявок вынесена в `components/TicketTable.vue`. Массив заявок передаётся компоненту через prop `items`.
7. Страницы списка заявок, создания заявки и входа размещены в `pages/TicketList.vue`, `pages/TicketNew.vue` и `pages/Login.vue`.
8. Общий реактивный массив и функцию добавления заявки вынесены в `ticketsStore.js`, чтобы список и форма использовали один источник данных.
9. Существующие визуальный стиль, тестовые заявки и валидация формы сохранены.

## Схема взаимодействия компонентов

```text
App.vue
├── AppHeader.vue  (постоянная навигация)
└── RouterView
    ├── TicketList.vue
    │   └── TicketTable.vue  (items ← ticketsStore.requests)
    ├── TicketNew.vue  (createTicket → ticketsStore)
    └── Login.vue
```

## Проверка работы

После установки зависимостей приложение запускается командой `npm run dev` из каталога `frontend`.

Проверить необходимо:
- открытие `/` и отображение списка заявок;
- открытие `/new` и отображение формы создания заявки;
- открытие `/login` и отображение формы входа;
- переходы по ссылкам боковой навигации без полной перезагрузки приложения;
- прямое открытие URL `/new`;
- создание заявки и отображение новой записи в списке;
- поиск по таблице.

**Примечание:** данные учебные, хранятся в реактивном массиве на стороне клиента и не сохраняются после перезагрузки страницы. Серверная авторизация, ASP.NET Core API и PostgreSQL в рамках этой работы не подключаются.

## Вывод

В ходе лабораторной работы клиентское приложение было разделено на страницы и переиспользуемые компоненты. Настроена маршрутизация Vue Router для списка заявок, формы создания и входа в систему. Общая навигация вынесена за пределы `RouterView`, а компонент таблицы получает данные через props. Для совместного доступа страниц к заявкам создан единый реактивный источник данных.
